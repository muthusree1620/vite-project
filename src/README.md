# 🛒 Add to Cart - ReactJS App

This is a responsive e-commerce ReactJS application that fetches product data from the [Fake Store API](https://fakestoreapi.com/) and allows users to add items to a shopping cart using a modal interface.

## 🚀 Features

- Fetches product list from Fake Store API
- Displays product image, title, price, and "Add to Cart" button
- Responsive design with Tailwind CSS
- Cart functionality:
  - Add items to the cart
  - Prevents duplicate additions with alert message
  - Displays cart count in the Navbar
  - Shows a modal with cart items
  - "Remove from Cart" option in the modal
- Clean and reusable component-based architecture
- Mobile-first responsive design

## 🛠 Tech Stack

- ReactJS
- Tailwind CSS
- JavaScript
- HTML/CSS
- Fake Store API
